# Theory Class 1 — Express.js Setup & EJS Template Rendering

**Course:** Backend Web Development  
**Directory:** `TheoryClass/Class1/`  
**Technologies:** Node.js, Express.js, EJS

---

## 1. Overview
Theory Class 1 introduces server-side development in Node.js using the **Express.js** web application framework and dynamic server-side rendering with **EJS (Embedded JavaScript)** templates.

---

## 2. Directory Contents
- `express-demo/`: Basic Express server initialization (`server.js`), demonstrating routing and static JSON responses.
- `task_2/`: Server-side templating using EJS, rendering dynamic student profiles (`Student.ejs`, `views/home.ejs`).

---

## 3. Running the Implementations
```bash
# Running Express Demo
cd TheoryClass/Class1/express-demo
npm install
node server.js

# Running EJS Task
cd ../task_2/venv
npm install
node server.js
```
