# Theory Class 2 — Web DevTools, API Fundamentals & Postman

**Course:** Backend Web Development  
**Directory:** `TheoryClass/Class2/`  
**Topics:** Browser Developer Tools, HTTP Methods, API Testing with Postman

---

## 1. Overview
Theory Class 2 covers essential development and debugging tooling for modern backend engineers:
- **Browser Developer Tools:** Network tab inspection, HTTP request/response headers, status codes (`200 OK`, `201 Created`, `400 Bad Request`, `404 Not Found`, `500 Internal Server Error`), payload inspection, and cookies.
- **Postman API Client:** Crafting and testing HTTP requests (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`), passing JSON request bodies, setting custom headers (`Content-Type: application/json`, `Authorization`), and inspecting API responses.
