# Unit III: Frameworks and Performance Optimization

**Course:** Backend Development (`CSFS3008P`)  
**Lecture Hours:** 12

## Contents
- `django/` (`dJango/`) — Django Task Manager API demonstrating routing, custom timing/logging middleware (`RequestTimingMiddleware`), `LocMemCache` caching, JSON error handling, and unit tests.

## Syllabus Topics
- Introduction to popular backend frameworks (e.g., Express.js, Django, Ruby on Rails)
- Working with middleware and routing
- Integrating third-party APIs and services
- Testing and debugging backend applications
- Understanding security vulnerabilities and best practices
- Implementing secure authentication and authorization mechanisms
- Caching and performance optimization techniques
- Error handling and logging
