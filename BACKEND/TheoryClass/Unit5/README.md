# Unit V: Advanced Topics

**Course:** Backend Development (`CSFS3008P`)  
**Lecture Hours:** 12

## Syllabus Topics
- Real-time communication with WebSockets
- Microservices architecture and design patterns:
  - Overview of microservices architecture and its benefits
  - Service discovery and service registration
  - Implementing communication between microservices (REST, messaging)
- Serverless computing:
  - Understanding serverless architecture and its advantages
  - Building serverless backend systems (AWS Lambda, Google Cloud Functions)
  - Event-driven serverless architecture and integration with other services
  - Function-as-a-Service (FaaS)
- Performance profiling and optimization strategies
