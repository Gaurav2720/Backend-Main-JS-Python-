# Experiment 1: HTML5 Web Page Structure

## Aim
To create a simple web page using HTML5 semantic elements and basic form, media, and multimedia features.

## Objectives
- Understand the structure of an HTML5 document.
- Use semantic tags such as header, nav, main, section, article, aside, and footer.
- Implement form controls, progress bars, and meter elements.
- Add audio and video elements to a webpage.

## Theory
HTML5 introduced semantic elements that make web pages more meaningful and easier to understand. These tags improve accessibility, SEO, and maintainability. Elements like header, nav, main, section, article, and footer help organize content clearly.

HTML5 also supports modern form elements such as date, color, email, and range input types. Multimedia support is improved through the audio and video tags, which allow media content to be embedded directly in webpages.

## Procedure
1. Created an HTML5 document with the required DOCTYPE and metadata.
2. Added a header, navigation bar, main content area, and footer.
3. Inserted a semantic article section with a figure and image.
4. Added a sidebar containing lists, progress, and meter elements.
5. Created a contact form using different input types.
6. Embedded audio and video elements into the page.

## Observations
- The page structure became more readable and organized using semantic tags.
- The use of form controls made the page interactive and modern.
- Audio and video elements were successfully embedded with built-in controls.
- The layout clearly separated content, navigation, and supplementary information.

## Conclusion
This experiment demonstrated the importance of HTML5 semantic elements in building well-structured and accessible web pages. The use of modern form controls and multimedia support enhanced both the functionality and user experience of the webpage.
