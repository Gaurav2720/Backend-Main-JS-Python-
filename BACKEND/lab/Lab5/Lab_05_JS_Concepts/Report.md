# Lab Experiment 05

**Course Outcome:** CO2 – Create and build web pages and applications.

## Topic
Programs to demonstrate JavaScript array, object and functions

## Objective
By the end of this lab, students will be able to:
1. Initialize and manipulate JavaScript arrays.
2. Define and access properties in JavaScript objects.
3. Write and invoke JavaScript functions to modularize code.

## PBL Activity
Implement a simple data management utility using Arrays and Objects.
- **Problem Scenario**: Manage a list of library books in a web application. Each book is an object. Functions are created to add a new book to the list and to find a book by its title.

## Source Code & Execution

### 1. Basic JavaScript (`script.js`)
Demonstrates Arrays, Objects, and Functions.
*(Executed via Node.js: `node script.js`)*

### 2. Advanced JavaScript Methods (`script2.js`)
Demonstrates string, array, and object manipulation methods.
*(Executed via Node.js: `node script2.js`)*

### 3. PBL Activity (`pbl.js`)
Implementation of the simple library management utility.
*(Executed via Node.js: `node pbl.js`)*

### 4. HTML Integration (`index.html`)
Integration of the scripts to execute within a browser environment.

## Output
*(Students can run `node script.js`, `node script2.js`, and `node pbl.js` in the terminal or open `index.html` in a web browser to view the console output)*

## Summary / Key Takeaways
- **Arrays** manage ordered lists of data.
- **Objects** store structured data as key-value pairs.
- **Functions** encapsulate logic, promoting reusability.
